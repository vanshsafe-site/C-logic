# C-logic

This repository is where I will store all my C code — everything that's taught to me.

## About

A personal collection of C programs, exercises, notes, and small projects to track learning progress and keep examples organized.

## Repository structure

- tutorials/    - code and examples from tutorials and lessons
- assignments/  - practice problems and homework
- projects/     - larger programs and multi-file projects
- snippets/     - small utility functions and examples
- docs/         - notes, explanations, and references

Create folders as needed and name files clearly, for example `arrays_01.c` or `sorting_quick.c`.

## How to compile and run

Use GCC to compile C files:

```bash
gcc filename.c -o filename
./filename
```

For multi-file projects, compile with:

```bash
gcc file1.c file2.c -o program
./program
```
